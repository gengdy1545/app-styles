# Codex · 莫兰迪配色方案

一组适用于 Codex Desktop 的暖灰莫兰迪配色，以低饱和鼠尾草绿作为强调色。

Codex 目前通过 **Settings → Appearance** 配置外观，并不是直接加载 CSS。按照下面的参数分别设置 Light theme 和 Dark theme 即可。

## Light theme

- Accent：`#7A8B7C`
- Background：`#EEEAE4`
- Foreground：`#3A3836`
- UI font：`System default · Regular`
- Content font：`Same as UI font · Regular`
- Code font：`System default · Regular`
- Translucent sidebar：开启
- Contrast：`36`

## Dark theme

- Accent：`#9BAE9D`
- Background：`#2B2A28`
- Foreground：`#E4DFD8`
- UI font：`System default · Regular`
- Content font：`Same as UI font · Regular`
- Code font：`System default · Regular`
- Translucent sidebar：关闭
- Contrast：`60`
